# Alpa Stitch Calculator

A single-page calculator for flat-stitched captures on Alpa 12 technical cameras.

Pick a digital back, lens, body, orientation, shift and print resolution to see:

- stitched pixel dimensions, megapixels and aspect ratio
- print size in inches and centimetres at the chosen ppi
- full-frame equivalent focal length and angle of view
- a to-scale frame layout against the lens's image circle
- the same setup on every back, flagged when it goes past Alpa's published shift limits or outside the image circle

## Coverage

- **Bodies:** Alpa 12 TC, SWA, STC, PLUS, PANO
- **Lenses:** Rodenstock/Alpa HR Alpagon 23, 32, 40, 50, 70, 90, 138 and HR Alpar 180
- **Backs:** Phase One IQ3 50MP, IQ3 100MP, IQ4 150MP; Hasselblad CFV-50c, CFV II 50C, CFV 100C

Lens image circles and movement limits are Alpa's published figures. Sensor figures are from the manufacturers' datasheets.

## Use

Open `index.html` in a browser. It has no build step and no dependencies beyond Google Fonts.

To host it, enable GitHub Pages on the repository (Settings → Pages → Deploy from a branch → `main` / root).

---

Not an official Alpa tool. Check your own setup before relying on these numbers.
